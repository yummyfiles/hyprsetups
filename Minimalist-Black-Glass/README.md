# Minimalist Black Glass

Pure black & white rice. monochrome everything.

## What is part of it:
- Hyprland (hyprland.lua)
- Waybar (black/white, Power menu via rofi power.rasi)
- Rofi launcher (bw.rasi)
- kitty + cava audio visualizer
- Swift notification daemon (notify-daemon.py)
- eww widgets
- Firefox black/white theme + startpage
- Qt/GTK monochrome (Kvantum + qt6ct, nwg-look, xsettingsd)
- Stoat black/white theme injector

## Install
```sh
sh ../install.sh
```
